## Projects

- **Programa de modernização .NET** (2024-2025)

Liderou a modernização de mais de 30 APIs Web e Aplicações de Console legados, migrando de versões .NET Framework fora de suporte (< 4.6.1) para .NET 8, melhorando confiabilidade da plataforma, manutenibilidade, postura de segurança e preparação para nuvem nativa.

Principais contribuições incluíram:

- Projetou e evoluiu a arquitetura de infraestrutura necessária para suportar aplicações modernizadas no Azure Kubernetes Service (AKS).
- Melhorou a linha de base existente do cluster AKS para suportar cargas de trabalho em nível de produção, incluindo:
- Monitoramento de memória, threads e requisições por segundo (RPS)
- Verificações de saúde da aplicação e probes de readiness/liveness
- Métricas padronizadas de observabilidade e operacionalidade
- Implementou gerenciamento de imagens de contêiner e fluxos de trabalho de implantação usando Container Registry e Helm.
- Aprimorou templates de pipeline CI/CD para automação de compilação e implantação, possibilitando entrega de aplicações mais consistente e escalável.
- Auxiliou equipes na adoção de práticas de containerização e operacionalidade do Kubernetes durante o processo de migração.
- Reduziu débito técnico associado a aplicações .NET Framework não suportadas e possibilitou escalabilidade futura da plataforma.

- **Templates de Pipeline Azure DevOps** (2023)

Projetou e implementou uma plataforma escalável "Template de Templates" para padronizar práticas de infraestrutura e CI/CD em múltiplas equipes de engenharia.

O projeto focou em criar templates reutilizáveis, modulares e gerenciados centralmente que aceleraram a integração de novos projetos, enquanto aplicavam padrões e melhores práticas organizacionais.

- Repositórios de Aplicações
  - Consumiram templates reutilizáveis de um repositório centralizado de pipelines.
  - Permitiram que equipes customizassem implantações mantendo padrões de governança e entrega padrões.

- Repositório Central de Pipeline
  - Hospedou templates compartilhados de CI/CD, módulos de infraestrutura e padrões de implantação.
  - Serviu como fonte única de verdade para práticas de construção, implantação e automação de infraestrutura.

Os principais resultados incluíram:

- Redução de lógica de pipeline duplicada entre equipes e repositórios.
- Melhoria na consistência, manutenibilidade e governança de fluxos de trabalho CI/CD.
- Aceleração da integração para novos projetos e equipes de engenharia.
- Permitiu adoção escalável de Infraestrutura como Código (IaC) e padrões de implantação.
- Aumento na confiabilidade de entrega através de componentes de pipeline reutilizáveis e versionados.

- **Team Foundation Server (TFS) migration to Azure DevOps (2020)**

Before I joined the project, the team lacked experience and technical knowledge related to server migrations and modernization initiatives. This created significant challenges for the company’s transition from legacy on-premises infrastructure and source control systems to the Azure ecosystem and modern DevOps practices. I played a key role in enabling and guiding the migration initiative, helping unblock the team and establish the technical direction for the project. The project successfully modernized the company’s development platform and became a key milestone in the adoption of Azure DevOps and cloud-based engineering practices. The migration enabled the team to adopt modern source control strategies, improve collaboration, reduce dependency on legacy infrastructure, and accelerate the organization’s transition to a more scalable and maintainable DevOps environment.

My contributions included:

- Leading the planning, validation, and migration of the on-premises server infrastructure to Azure Virtual Machines.
- Supporting the migration from Team Foundation Server (TFS) to Azure DevOps Services in the cloud.
- Assisting the team in understanding modern DevOps workflows, cloud infrastructure concepts, and migration best practices.
