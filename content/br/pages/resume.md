## Projects

- **Team Foundation Server (TFS) migration to Azure DevOps (2020)**

Before I joined the project, the team lacked experience and technical knowledge related to server migrations and modernization initiatives. This created significant challenges for the company’s transition from legacy on-premises infrastructure and source control systems to the Azure ecosystem and modern DevOps practices. I played a key role in enabling and guiding the migration initiative, helping unblock the team and establish the technical direction for the project. The project successfully modernized the company’s development platform and became a key milestone in the adoption of Azure DevOps and cloud-based engineering practices. The migration enabled the team to adopt modern source control strategies, improve collaboration, reduce dependency on legacy infrastructure, and accelerate the organization’s transition to a more scalable and maintainable DevOps environment.

My contributions included:

- Leading the planning, validation, and migration of the on-premises server infrastructure to Azure Virtual Machines.
- Supporting the migration from Team Foundation Server (TFS) to Azure DevOps Services in the cloud.
- Assisting the team in understanding modern DevOps workflows, cloud infrastructure concepts, and migration best practices.


- **Datacenter refresh - Storage, Switching and servers (2017-2020)**

Planning and executing hardware migration projects with different virtualization solutions like VMware and Hyper-V, migrating from any "vendor" solution to a new Dell Technologies stack hardware. Helping customers achieve migrations from legacy clusters to new ones, moving storage and virtual machines, and teaching the operational team the new environment tooling.

- **Microsoft Exchange Server migration (2017-2020)**

Experienced in migrating small and mid-sized companies, including upgrading Exchange Server environments and transitioning data to Office 365 with Exchange Online. Led a key project during an M&A process, migrating accounts from an on-premises Exchange environment to the cloud, ensuring a seamless transition with no user impact or downtime.

- **Re-architecting network Infrastructure (2017-2020)**
    
As a network engineer, I handled a bunch of tasks about poor networking performance, Spanning Tree Protocol (STP) issues, or network subnet limitations in customers' network infrastructure. 
Dealing with customer sites for planning, network changes, and applying them on network devices like firewalls, switches, routers and network services (e.g., DHCP, DNS, and VPNs). 

From the design to the execution, including
- Drawing network design
- Create project Scope
- Planning the phases, steps, checks, and rollback plan
