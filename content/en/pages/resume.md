## Projects

- **Dotnet modernization program** (2024-2025)

Led the modernization of more than 30 legacy Web APIs and Console Applications from End-of-Life .NET Framework versions (< 4.6.1) to .NET 8, improving platform reliability, maintainability, security posture, and cloud-native readiness.

Key contributions included:

- Designed and evolved the infrastructure architecture required to support modernized applications on Azure Kubernetes Service (AKS).
- Improved the existing AKS cluster baseline to support production-grade workloads, including:
- Memory, thread, and requests-per-second (RPS) monitoring
- Application health checks and readiness/liveness probes
- Standardized observability and operational metrics
- Implemented container image management and deployment workflows using Container Registry and Helm.
- Enhanced CI/CD pipeline templates for build and deployment automation, enabling more consistent and scalable application delivery.
- Helped teams adopt containerization and Kubernetes operational practices during the migration process.
- Reduced technical debt associated with unsupported .NET Framework applications and enabled future platform scalability.

- **Azure DevOps Pipeline Templates** (2023)

Designed and implemented a scalable “Template of Templates” platform to standardize infrastructure and CI/CD practices across multiple engineering teams.

The project focused on creating reusable, modular, and centrally managed templates that accelerated project onboarding while enforcing organizational standards and best practices.

- Application Repositories
  - Consumed reusable templates from a centralized pipeline repository.
  - Allowed teams to customize deployments while maintaining standard governance and delivery patterns.

- Central Pipeline Repository
  - Hosted shared CI/CD templates, infrastructure modules, and deployment standards.
  - Served as the single source of truth for build, deployment, and infrastructure automation practices.

Key outcomes included:

- Reduced duplicated pipeline logic across teams and repositories.
- Improved consistency, maintainability, and governance of CI/CD workflows.
- Accelerated onboarding for new projects and engineering teams.
- Enabled scalable adoption of Infrastructure as Code (IaC) and deployment standards.
- Increased delivery reliability through reusable and versioned pipeline components.

- **Team Foundation Server (TFS) migration to Azure DevOps (2020)**

Before I joined the project, the team lacked experience and technical knowledge related to server migrations and modernization initiatives. This created significant challenges for the company’s transition from legacy on-premises infrastructure and source control systems to the Azure ecosystem and modern DevOps practices. I played a key role in enabling and guiding the migration initiative, helping unblock the team and establish the technical direction for the project. The project successfully modernized the company’s development platform and became a key milestone in the adoption of Azure DevOps and cloud-based engineering practices. The migration enabled the team to adopt modern source control strategies, improve collaboration, reduce dependency on legacy infrastructure, and accelerate the organization’s transition to a more scalable and maintainable DevOps environment.

My contributions included:

- Leading the planning, validation, and migration of the on-premises server infrastructure to Azure Virtual Machines.
- Supporting the migration from Team Foundation Server (TFS) to Azure DevOps Services in the cloud.
- Assisting the team in understanding modern DevOps workflows, cloud infrastructure concepts, and migration best practices.
